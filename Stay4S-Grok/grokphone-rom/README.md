# GrokPhone ROM

Dit is de custom ROM configuratie voor de Stay4S GrokPhone.

**Doel**: Een volledig geïntegreerde LineageOS 22.1 (Android 15) ROM voor de Nothing Phone (asteroids) waarbij `com.xai.grok` de privileged system app is met eigen launcher, deep system integration en eigen boot ervaring.

## Belangrijkste mappen

- `device/nothing/asteroids/` — Product definitie, SELinux, init scripts
- `packages/apps/Grok/` — De privileged Grok app
- `scripts/` — Build en sync tools
- `docs/` — Architectuur documenten en checklists
